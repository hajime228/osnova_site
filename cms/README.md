# Как Фариде добавлять статьи без редактирования сайта

## Один раз: создать таблицу и API

1. Откройте https://script.google.com и создайте новый проект.
2. Вставьте содержимое файла `Code.gs`.
3. Запустите функцию `setupArticlesSheet` и разрешите доступ.
4. В журнале выполнения появится ссылка на таблицу.
5. Нажмите **Развернуть → Новое развертывание → Веб-приложение**.
6. Выполнять от имени: **я**. Доступ: **все**.
7. Скопируйте URL, который заканчивается на `/exec`.
8. В файле сайта `js/articles-config.js` вставьте URL между кавычками.
9. Загрузите изменённый файл в GitHub. Это делается только один раз.

## Как публиковать новую статью

Добавьте строку в таблицу и заполните:

- **Статус:** `Черновик` или `Опубликовано`;
- **Дата**;
- **Категория:** обучение, развитие, педагогика и т. п.;
- **Заголовок**;
- **slug:** короткий адрес латиницей, например `kak-uchitsya`;
- **Краткое описание** для карточки;
- **Текст статьи**. Поддерживаются теги `<p>`, `<h2>`, `<h3>`, `<ul>`, `<li>`, `<blockquote>`;
- **Ссылка на обложку** — необязательно;
- **Время чтения**, например `6 минут`.

Чтобы статья появилась на сайте, установите статус **Опубликовано**. Она загрузится автоматически; GitHub обновлять не нужно.

Важно: не вставляйте в таблицу неизвестный HTML или скрипты. Доступ к таблице должен быть только у автора и доверенных редакторов.
