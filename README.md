ЦОР «ОСНОВА»

Сайт центра осознанного развития «ОСНОВА» — индивидуальные занятия по черчению и инженерной графике для школьников и студентов.

Сайт: https://osnova.site-sd.workers.dev

О проекте

Сайт знакомит с направлениями обучения, помогает подобрать формат занятий и показывает реальный пример учебной задачи с пошаговой анимацией решения.

Основные направления:

черчение;

инженерная графика;

начертательная геометрия;

развитие пространственного мышления;

помощь школьникам и студентам;

профориентация для тех, кто рассматривает технические и инженерные направления.
